# HospitalResourceUtilization

This project contains a simple hospital login page (`login.html`) and a dashboard (`dashboard.html`) built with HTML, CSS, and JavaScript.

## Demo Credentials

## Usage
1. Open `login.html` in a browser.
2. Enter one of the demo credentials.
3. After login, you will be redirected to the dashboard.
